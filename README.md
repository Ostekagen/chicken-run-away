# Chicken Run Away

A 2D browser platformer about a chicken escaping the slaughterhouse with the
butcher in pursuit. See [the project plan](docs/PLAN.md).

## Running it

```bash
npm install
npm run dev
```

Then open http://localhost:5173. Move with the arrow keys or A/D, and jump with
Space, Up or W. Tune the feel in `src/config.ts`.
