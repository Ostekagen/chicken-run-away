# Chicken Run Away

A 2D browser platformer about a chicken escaping the slaughterhouse with the
butcher in pursuit. See [the project plan](docs/PLAN.md).

## Running it

```bash
npm install
npm run dev
```

Then open http://localhost:5173. Move with the arrow keys or A/D, jump with
Space, Up or W, throw eggs with X, crow with C, pause with P and mute with M.
Phones and tablets get on-screen buttons. Tune the feel in `src/config.ts`.
