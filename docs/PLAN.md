# Chicken Run Away - Project Plan

A forgiving, cartoonish browser platformer with no gore. A chicken escapes the
slaughterhouse and runs for freedom with the butcher after it. Game text is in
English and lives in one file, so a Danish version can be added later.

## Tech

- Phaser 3 and TypeScript, built with Vite, hosted on GitHub Pages
- 32x32 pixel tiles on a 640x360 screen, scaled up to fit
- Levels made in the free Tiled editor
- Stars and level progress stored in the browser

## Core rules

- **Controls:** keyboard, plus on-screen touch buttons in landscape
- **Health:** 3 hearts and 2-3 checkpoints per level, no game over
- **Caught by the butcher:** back to the latest checkpoint
- **Collectibles:** corn (100 restores a heart) and 3 hidden golden eggs per
  level, which give a 1-3 star rating

## Levels

1. **The Slaughterhouse:** teaches the controls, with meat-hook workers and
   rats, ending in a chase.
2. **The Farm:** more open, with guard dogs and an angry goose.
3. **The Road to Freedom:** the hardest chases, with foxes and a van to dodge.
4. **Boss:** dodge the butcher's cleavers and hit him with eggs until he is
   knocked into a pig pen or river. The chicken runs free.

The butcher appears in scripted chases, throws cleavers, and returns as the
final boss. Most enemies are defeated by jumping on them.

## Power-ups

The chicken holds one at a time. Picking up a new one replaces it.

| Power-up      | Effect                                    | Lasts    |
| ------------- | ----------------------------------------- | -------- |
| Egg Throw     | Throw eggs at enemies                     | Until hit |
| Flappy Wings  | Double jump and glide                     | Until hit |
| Feather Armor | Blocks a hit                              | One hit  |
| Corn Rush     | Speed boost                               | Timer    |
| Mighty Crow   | Stuns everything on screen, butcher too   | One use  |

## Art and sound

- Kenney CC0 tiles and sound effects
- Custom pixel art for the chicken, butcher and power-ups, generated by scripts
  so it can be redone
- CC0 chiptune music, with sources listed in the repo

## Build phases

1. **Foundation (one developer):** project setup, level loading, chicken
   movement, camera and a test level. Playtest the jump feel before moving on.
2. **Parallel agents (each in its own git worktree, working through reviewed
   pull requests):**
   - Agent A: power-ups
   - Agent B: enemies, chases and the boss
   - Agent C: art and sound
   - Agent D: the three levels
3. **Finish (one developer):** merge everything, menus and HUD, touch controls,
   balancing and automated browser checks, then publish to GitHub Pages. Final
   playtest.
